# PaperFlux Server

**Русский** | [English](README.en.md)

Серверная часть PaperFlux для собственного Linux-сервера. Она принимает соединения от совместимых клиентов PaperFlux и передаёт их во внешнюю сеть через выходной узел.

Android-клиент развивается отдельно: [PaperFlux Android](https://github.com/Flofyyk/PaperFluxAndroid).

## Возможности

- Выходной узел для Linux.
- Транспорт через Yandex Docs с WebSocket-соединением.
- Авторизация профилей и шифрование транспортных сообщений.
- Локальный SOCKS5-слушатель для тестирования с десктопным клиентом.
- Поддержка Android-клиента: передача TUN-дескриптора, проверка DNS/TCP и счётчики трафика.

## Требования

- Linux-сервер с правами root для режима выходного узла.
- Go 1.26.3 или новее.
- Данные профиля и ссылка на документ, созданные для вашего развёртывания.

## Сборка

```bash
go mod tidy
go build -o paperflux .
```

## Запуск выходного узла

```bash
sudo ./paperflux --exit-node --url "YOUR_DOCUMENT_URL"
```

## Локальная проверка

Команда ниже запускает клиент и открывает SOCKS5 на `127.0.0.1:1080`:

```bash
./paperflux --client --url "YOUR_DOCUMENT_URL" --socks5 :1080
```

Полный список параметров доступен через `./paperflux --help`.
