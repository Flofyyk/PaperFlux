## Изменения

- Транспорт Mail.ru адаптирован из актуального OpenFlux: порядок подключения и обработка всех курсоров в объединённых сообщениях.
- Добавлена периодическая активность редактора для редактируемых документов; ссылки только для чтения принимаются без отправки правок.

Для Mail.ru используйте отдельный пустой документ: активность редактора меняет его содержимое.
