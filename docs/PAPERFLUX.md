# Подключение PaperFlux Android

Сначала [разверните сервер](DEPLOYMENT.md), затем установите приложение из [релизов PaperFlux Android](https://github.com/Flofyyk/PaperFluxAndroid/releases).

## Параметры профиля

| Поле | Назначение |
| --- | --- |
| ID | Идентификатор профиля, совпадающий с серверным `--profile-id` |
| Токен | Секрет профиля, совпадающий с `--profile-token` |
| Документ | Ссылка Yandex Docs, общая для клиента и сервера |
| Виртуальный IP | IPv4-адрес клиента; должен совпадать с настройкой `--client-ip` соответствующего серверного процесса |
| Имя | Название профиля в приложении |

Для одного профиля можно использовать виртуальный IP `10.10.10.2` — это значение по умолчанию в серверном CLI. Наличие ID профиля само по себе не создаёт серверную базу пользователей: параметры передаются конкретному процессу PaperFlux.

Приложение принимает конфигурацию из файла, буфера обмена или ручного ввода. Для ручного ввода используйте одну или две ссылки `https://disk.yandex.ru/...`; две ссылки можно разделить запятой, `;` или новой строкой. В ссылках формата `paperflux://config` значения параметров, включая вложенную ссылку документа, должны быть URL-кодированы.

## Первое подключение

1. Откройте «Профили» и добавьте конфигурацию.
2. Выберите профиль и нажмите кнопку подключения на главной странице.
3. Подтвердите системное разрешение Android на VPN.
4. Дождитесь проверки защищённого канала и DNS/TCP.

Авторизация документа подтверждает доступ к транспорту. Статус подключения появляется после проверки связи через сервер.

## Диагностика

Если подключение не завершается, сравните параметры профиля с настройками сервера и проверьте серверный журнал: `sudo journalctl -u paperflux -f`.

В журнале клиента доступны этапы подключения и причины обрыва. Перед публикацией диагностических данных удалите секреты и ссылки доступа.
